# Assignment 17 - Advanced JavaScript Concepts

## Questions Covered
1. **Q1** - Student Result Processing (reduce + Classes)
2. **Q2** - Online Food Ordering (map + Error Handling)
3. **Q3** - Product Discount System (Constructor + Prototype)
4. **Q4** - Employee Inheritance (Runtime Polymorphism)
5. **Q5** - Ride-Sharing Application (Inheritance + Error Handling)
6. **Q6** - E-Commerce Inventory System (Array Methods)
7. **Q7** - Banking Application (Private Fields + Error Handling)
8. **Q8** - Movie Ticket Booking System (Inheritance + Prototype Chain)
9. **Q9** - Fitness App Analytics (Array Methods + Error Handling)

## Key Concepts Demonstrated
- ES6+ Classes and Inheritance
- Array methods: `map()`, `filter()`, `reduce()`, `sort()`
- Constructor functions and prototypes
- Runtime polymorphism (method overriding)
- Private fields (`#fieldName`)
- Error handling with `try-catch`
- Prototype chain
- Closures and abstraction

## How to Run
Execute each file with Node.js:
```bash
node Assignment_17/q1_student_result.js
node Assignment_17/q2_food_ordering.js
node Assignment_17/q3_product_discount.js
# ... and so on
```

Or run all at once:
```bash
Get-ChildItem Assignment_17/*.js | ForEach-Object { node $_.FullName; Write-Host "`n---`n" }
```
