What is jQuery? ▼
jQuery is a fast, small, and feature-rich JavaScript library. It makes things like HTML document traversal and manipulation, event handling, and animation much simpler with an easy-to-use API.
How do I install jQuery? ▼
You can include jQuery in your project by adding a CDN link in your HTML file or by downloading it locally. The CDN method is recommended for faster loading times.
What are jQuery selectors? ▼
jQuery selectors allow you to select and manipulate HTML elements. They are based on CSS selectors and also have custom selectors for more specific targeting. Examples: $('#id'), $('.class'), $('element').
What is event delegation in jQuery? ▼
Event delegation refers to the process of using event propagation (bubbling) to handle events at a higher level in the DOM than the element on which the event originated. It allows us to attach a single event listener to a parent element.
How do I make AJAX requests with jQuery? ▼
jQuery provides several methods for AJAX functionality: $.ajax(), $.get(), $.post(), and $.getJSON(). These methods make it easy to load data from the server without refreshing the page.
What are jQuery effects and animations? ▼
jQuery provides a variety of effects and animations like .hide(), .show(), .fadeIn(), .fadeOut(), .slideUp(), .slideDown(), and .animate() for custom animations. These make it easy to add visual effects to your web pages.
